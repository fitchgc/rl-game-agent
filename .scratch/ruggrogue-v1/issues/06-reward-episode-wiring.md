# 06: 接通奖励与回合结算

**What to build:** 将同一次 `on_frame` 的 HUD、阶段和结算屏结果接入奖励管线，完成可供训练与评估使用的完整 episode。

**Blocked by:** 05 (打通 BrowserGameEnv 与 adapter).

**Status:** ready-for-agent

- [ ] 深度仅突破本 episode 已达纪录时奖励 `+1.0`，升级 `+0.5`，死亡 `-1`、胜利 `+10`；经验微奖、掉血罚、步罚明确配置并锁定，不重复结算终局奖励。
- [ ] `terminated` 仅表示胜利或死亡；5000 回合预算、300 回合停滞、连续 20 次 OCR 失败触发 `truncated`，原因进入固定 `info`；停滞进展条件明确且可测试。
- [ ] 不可信 OCR 不参与数值差分、不造成虚假奖励；恢复可信读取、经验重置、HUD 消失和新局重置均有回放测试。
- [ ] 真实短局可输出逐步奖励分项与结束原因；用标注帧序列验证全部终止路径，并标记 OCR 等技术 fault，供评估剔除。
