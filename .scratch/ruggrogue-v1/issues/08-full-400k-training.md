# 08: 执行 400k 正式训练

**What to build:** 以锁定配置启动并完成 400k 步 PPO 训练，产出可追溯 checkpoint 序列及训练运行报告。

**Blocked by:** 07 (PPO 短程训练冒烟).

**Status:** ready-for-agent

> **前置实测（09 号票，2026-10-14）**：评估 harness 实测吞吐约 1.0 step/s（sync p50 649ms），慢于 08 号决策票假设的 ~2 step/s。按 1.0 step/s 计，400k 步需约 111 小时，超过 72h 墙钟中止线。执行本票前必须先做 10k 步吞吐校准，并按实测重定 total_timesteps 或墙钟预算（选项：降步数 / 延预算 / 优化吞吐），由用户确认后再启动。

- [ ] 记录代码版本、游戏文件校验值、依赖版本、seed、完整配置与中止规则；不擅自切换 DQN 或修改奖励。
- [ ] 每 10k 步保存 checkpoint，持续写入 TensorBoard；中断恢复后 timesteps 不归零、不覆盖既有模型，记录恢复事件。
- [ ] 提供启动、恢复和状态检查命令；长任务可无人值守，单 session 内完成执行准备与启动，不要求人工驻守全过程。
- [ ] 达到 400k 步后生成完成报告才标记完成；若触发中止，报告步数、原因及保留产物，不以提前中止冒充完成。
